seiton の使い方

ワークスペース単位でタブとブックマークを整理する Chrome 拡張機能です。このページは設定画面からいつでも開けます。

まず最初に 基本の考え方 管理パネル ワークスペースタブ クイックパレット ブックマーク ショートカット メモリ 設定 よくある質問

まず最初に（3 ステップ）

  1. 管理パネルを開く Alt+Shift+K を押すか、ツールバーの seiton アイコン → 右上の ☰ を押します。 今のウィンドウの上に一時的なウィンドウとして開きます（タブは増えません）。
  2. 最初のワークスペースを作る 「ワークスペース」見出し右の ＋ を押し、名前（例: 案件A）とアイコンを決めます。 すでにタブを開いているなら「今開いているタブをこのワークスペースにする」を選ぶと、そのまま引き継げます。
  3. 2 つ目を作って切り替えてみる もう 1 つ作ると、今のタブは閉じて新しいワークスペースに切り替わります。 一覧の行をクリック、または Alt+K → > で名前を打つと行き来できます。 閉じたタブは失われず、戻ると復元されます。
ツールバーのパズルアイコンから seiton をピン留めしておくと、ワンクリックでクイックパレットが開けます。 ピン留めした seiton アイコンは、ウィンドウごとに今のワークスペースの色とアイコン（絵文字が無ければ名前の頭文字）に変わり、ホバーすると名前が出るので、管理パネルを開かなくても今どこにいるか分かります（未割り当てのウィンドウでは元のアイコン）。

基本の考え方

🗂 ワークスペース

「案件A」「調べもの」など、タブのまとまり。1 つのウィンドウには 1 つのワークスペースだけが表示され、切り替えると他のワークスペースのタブは閉じて保存されます。

🔖 接続フォルダ

ワークスペースごとに結び付けたブックマークフォルダ。そのワークスペースで保存したブックマークはここに入り、パレットや管理パネルから検索できます。

🏷 セッション

「AWS 本番」「AWS 開発」「個人」のように、ワークスペースがどのアカウントで使うものかを表します。同じセッションのワークスペースを一括で開けます。セッションごとにログイン状態（Cookie）が分かれ、Chrome のプロファイルを切り替えるように使えます。

なぜタブを閉じるの？ Chrome にはタブを「隠す」API が無いため、切り替え時はタブを閉じて開き直します（Workona と同じ方式）。 URL・タイトル・固定・タブグループ・アクティブタブは保存され、戻ると復元されます。 フォームの入力途中の内容やスクロール位置は引き継がれないので、入力中のページがあるときは注意してください。

管理パネル Alt+Shift+K

ワークスペース一覧・接続フォルダのブックマーク・開いているタブを並べて表示する、seiton のメイン画面です。呼び出したウィンドウの上に一時的なウィンドウとして重なって開き、タブとしては残りません。「このウィンドウ」は呼び出したウィンドウを指します。

ワークスペースの切り替え・タブやブックマークを開くなど移動する操作をすると、自動で閉じます。Esc（入力中の検索や編集・ダイアログがあれば先にそれを閉じる）、他のウィンドウをクリックしてフォーカスを外す、もう一度 Alt+Shift+K を押す、でも閉じます。

上部の検索ボックス

  • ワークスペース（名前・セッション名・アイコン）、すべての接続フォルダのブックマーク、Chrome の閲覧履歴をまとめて検索します
  • ↑↓ で選択、Enter で開く。ワークスペースはこのウィンドウを切り替え、ブックマークはそのワークスペースが開いているウィンドウで開きます
  • Shift+Enter: ワークスペースは新しいウィンドウで、URL はこのウィンドウで開く
  • / でどこからでも検索ボックスにフォーカス、Esc で検索語を消す（空ならパネルを閉じる）

ヘッダーのボタン

  • ワークスペース管理: 切り替えずに、すべてのワークスペースを一覧で編集するダイアログ。行ごとに名前・セッション・自動クローズをその場で変更（▼ で色とアイコン）、⋮⋮ をドラッグして並び替え、「削除」で 1 件削除。チェックを入れた行には「セッション / 色 / 自動クローズ」を一括で適用したり、まとめて削除したりできます（ブックマークフォルダは消えません）。ブックマークフォルダの接続は ✎ から
  • 閉じたタブ: タブの自動クローズで閉じたタブの履歴（件数があればボタンに表示）。日付ごとにタイトル・ホスト・ワークスペース・閉じた時刻を並べ、行をクリックで開き直します（そのワークスペースが別ウィンドウで開いていればそちら。開き直した分は履歴から消えます）。タイトル・URL で絞り込み、× で 1 件ずつ、「すべて削除」で一括削除。最大 500 件で、古いものから消えます
  • セッション: セッションの追加・名前変更・削除、「全て開く」（そのセッションを使う全ワークスペースを別ウィンドウで一括オープン）。削除したセッションを使っていたワークスペースは別のセッションに付け替えられ、ワークスペース自体は消えません
  • 非アクティブなタブを休止: このウィンドウの使っていないタブのメモリを今すぐ解放します（タブは残ります）
  • ⚙: 設定画面を開く

ワークスペースに割り当てていないウィンドウでは「今のタブをワークスペースとして保存」できます。

ワークスペースタブ

ワークスペースのウィンドウでは、タブ列の左端（固定タブがあればその直後）に、ワークスペースの色で「絵文字 名前」のラベルが常に表示されます。どのウィンドウが今どのワークスペースか、タブ列を見るだけで分かります。

  • ラベルは seiton のページ 1 枚だけが入ったタブグループで、ふだんは折りたたまれています。クリックすると開き、中のタブで次のことができます
    • 今のワークスペース（アイコン・名前・セッション）の確認
    • 全ワークスペースの一覧: クリックでこのウィンドウを切り替え、⧉ で新しいウィンドウで開く（別ウィンドウで開いていればそちらへ移動）
    • 「管理パネルを開く」
    • 接続フォルダのブックマーク（クリックで新しいタブで開く）
  • ワークスペースを切り替えると、ラベルの色と名前が切り替え先のものに変わります。✎ で名前・色・アイコンを変えたときも追従します
  • 閉じたりグループから外したりしても自動で元に戻ります。表示したくない場合は設定の「ワークスペースタブ」を OFF にしてください
  • このタブとラベルのグループはワークスペースに保存されず、あなた自身のタブグループの保存・復元には影響しません。パレットや管理パネルのタブ一覧にも出ません

クイックパレット Alt+K

今のタブ・接続フォルダのブックマーク・ワークスペースをインクリメンタル検索して、キーボードだけで移動するための小さなウィンドウです。

キー動作
↑ ↓ / Enter選択 / 開く
> を先頭に入力、または Tabワークスペースだけを検索するモードに切り替え（全角 ＞ も可）
タブを選んで Deleteそのタブを閉じる
ブックマークを Enter既に開いていればそのタブへ、無ければ新しいタブで開く。Shift+Enter で現在のタブで開く
ワークスペースを Enterこのウィンドウを切り替え。Shift+Enter で新しいウィンドウ

ブックマーク

  • ワークスペースごとに任意のブックマークフォルダを「接続」できます（新規作成 or 既存フォルダを選択）。新規作成したフォルダは「その他のブックマーク」の中の Workspaces フォルダに入ります（親フォルダ名は設定で変更可）
  • ワークスペースを表示中に Ctrl+D や ☆ で作ったブックマークは、自動で接続フォルダへ移動します（設定で OFF にできます）
  • Alt+Shift+D で、今のタブを接続フォルダに直接保存。拡張アイコンのバッジに +（保存した）、=（保存済みだった）、!（フォルダ未接続などで保存できない。理由はアイコンのツールチップ）が出ます
  • ブックマークマネージャーや他端末からの同期で作られたブックマークは移動しません
  • ワークスペースを削除してもブックマークフォルダと中身は残ります。逆に接続中のフォルダを削除すると、接続だけが自動で解除されます

ショートカット

現在この Chrome に割り当てられているキーです（ で変更できます）。

キー動作
Alt+K などが IME や他のアプリと衝突する場合はショートカット設定で変更してください。 「前のワークスペースへ」は既定キーが無いので、使う場合はここで割り当てます。

メモリ

ワークスペースを切り替えると他のワークスペースのタブは閉じるため、同時に開いているタブの数そのものが減ります。これが一番大きなメモリ削減です。そのうえで次の 2 つを提供します。

  • 遅延読み込み（既定 ON）: ワークスペースを開くとき、前面だったタブ 1 件だけを読み込み、他のタブはクリックした時点で読み込みます
  • 自動休止（既定 OFF）: 「N 分以上使っていないタブを確実に休止したい」場合だけ設定で有効化。固定タブと音声再生中のタブは対象外です
推奨設定は、Chrome 標準のメモリセーバー（）を ON にして、seiton は既定のままにすることです。 メモリセーバーはメモリ逼迫度やフォーム入力中などの状態を見て休止するため、拡張から一律に休止するより安全です。

タブの自動クローズ（既定 OFF）

最後に使ってから一定の期間（既定 7 日。分 / 時間 / 日で指定でき、最短 15 分）が経ったタブを、休止ではなく閉じます。設定画面の「タブの自動クローズ」で ON にし、期間を決めます。ワークスペースごとに、管理パネルの ✎ の「自動クローズ」で「設定に従う / 無効 / 有効（期間）」を選んで上書きできます。

  • 15 分ごとに確認します。固定タブ・音声再生中のタブ・各ウィンドウのアクティブなタブ・seiton 自身のページは閉じません。ウィンドウの最後の 1 枚も閉じません
  • 閉じたタブはワークスペースの保存内容からも外れます。管理パネルの「閉じたタブ」（最大 500 件、一括削除可）や Chrome の履歴（Ctrl+H）から開き直せます
  • 対象は今開いているタブだけです。開いていないワークスペースの保存済みタブは閉じられません
  • 閉じたくないページは除外できます。管理パネルの「開いているタブ」の行にマウスを乗せると出る 🛡 を押し、「このページ」（この URL とその下）か「このサイト全体」（サブドメインも含む）を選んで除外リストに追加します。除外中のタブには「除外」バッジが出て、クリックで解除できます。一覧の編集・削除は設定画面の「タブの自動クローズ」→「除外する URL」で。github.com（サイト全体）、mail.google.com/mail（ホスト + パスの先頭）、https://example.com/docs（URL の先頭）のように書け、* は任意の文字列です

設定

管理パネル左下の「⚙ 設定」、またはこのページ上部の「設定を開く」から開きます。

  • 表示: ウィンドウ左端のワークスペースタブ（色付きのグループ）の ON/OFF
  • メモリ: 遅延読み込みの ON/OFF、自動休止までの分数
  • タブの自動クローズ: 長期間使っていないタブを自動で閉じるかと、閉じるまでの期間（分 / 時間 / 日。ワークスペースごとの上書きは管理パネルの ✎）、閉じない URL の除外リスト（追加・編集・削除）
  • ブックマーク: Ctrl+D の自動移動の ON/OFF、ワークスペース用フォルダの親フォルダ名
  • ショートカット: 現在の割り当ての確認と変更画面へのリンク
  • バックアップ: ワークスペース・セッション設定の JSON エクスポート / インポート（ブックマークそのものと閉じたタブの履歴は含みません。インポートすると現在の設定はすべて置き換わります）、閉じたタブの履歴の一括削除

よくある質問

Chrome を再起動したらどうなる？

各ウィンドウに開いているタブの URL と、保存されたワークスペースの URL の重なりから、自動でウィンドウとワークスペースを対応付け直します。「前回開いていたページを開く」が OFF の場合は、最後に使っていたワークスペースを開きます。

ワークスペースに割り当てていないウィンドウで、別のワークスペースに切り替えたら？

そのウィンドウのタブは「未整理 M/D HH:mm」というワークスペースとして自動保存してから切り替えます。タブは失われません。

同じワークスペースを 2 つのウィンドウで開ける？

開けません。1 つのワークスペースは同時に 1 ウィンドウだけです。2 つ目を開こうとすると既存のウィンドウにフォーカスします。

セッションを分けると Cookie やログイン状態も分かれる？

分かれます。管理パネルの「セッション」で 2 つ目のセッションを追加するときに、Cookie を読み書きする権限（すべてのサイト）の確認が出ます。許可すると、別のセッションを使うワークスペースに切り替えるたびに、今の Cookie をそのセッション用に退避してすべて消し、切替先のセッションの Cookie を復元します。許可した時点の Cookie は、そのとき開いていたワークスペースのセッションのものになり、新しいセッションは未ログインの状態から始まります（そのセッションのワークスペースでログインすれば、以後そのセッション用に保たれます）。権限を拒否するとセッションは追加されません。後から chrome://extensions で権限を取り消すと分かれなくなり、管理パネルの「セッション」と設定画面に「権限を許可する」が出ます。

Chrome にはウィンドウやタブごとに Cookie を分ける仕組みが無いため、同時に使えるセッションは 1 つです。切替は全ウィンドウに及び、別のセッションのワークスペースを開いたままのウィンドウは、次にページを読み込んだときから切替先のログイン状態になります（混ざらないよう、そのセッションを使うウィンドウは閉じるか、同じセッションのワークスペースだけを並べて使うのがおすすめです）。localStorage などサイト側の他の保存領域は分けません。退避した Cookie は拡張の保存領域に平文で保存され、エクスポートには含まれません。完全に分けたい場合は、これまで通り Chrome のプロファイルを分けてください。

開けないページがある

chrome:// の一部や file:// は拡張から開けないことがあり、その場合は復元をスキップします。シークレットウィンドウも対象外です。

フォームの入力途中の内容、ページ内のスクロール位置、タブごとの戻る / 進む履歴は、ワークスペース切り替えで引き継がれません。
