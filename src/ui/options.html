ワークスペース

切り替えずに、すべてのワークスペースをここで編集できます。名前・セッション・自動クローズは行で変えるとすぐ保存され、▼ で色とアイコンを開きます。左端の ⋮⋮ をドラッグすると並び替え（管理パネルの一覧でも行をドラッグできます）。チェックを入れた行には下の一括変更を適用します。新しいワークスペースの作成とブックマークフォルダの接続は管理パネル（＋ / ✎）から。

セッション

ワークスペースが「どのアカウント / ログイン状態で使うか」を表します。セッションごとに Cookie（ログイン状態）が分かれ、Chrome のプロファイルを切り替えるように使えます。各ワークスペースが使うセッションは「ワークスペース」の節か管理パネルの ✎ で選びます。

Cookie の状態

別のセッションを使うワークスペースに切り替えるとき、今の Cookie をそのセッション用に退避してすべて消し、切替先のセッションの Cookie を復元します（Chrome のプロファイルを切り替えるのに近い動き）。 Chrome 全体で同時に使えるセッションは 1 つで、切替は他のウィンドウにも及びます（別のセッションのワークスペースを開いているウィンドウは、次の読み込みから切替先のログイン状態になります）。 Cookie を読み書きする権限（すべてのサイト）が必要で、2 つ目のセッションを追加するときに Chrome が確認を出します。localStorage などサイト側の他の保存領域は分けません。 退避した Cookie はこの拡張の保存領域（chrome.storage.local）に AES-GCM で暗号化して保存され（鍵はこのブラウザの外に出せない形で保持）、エクスポートや同期には含まれません。
「退避した Cookie を削除」は退避した分だけを消します（今 Chrome に入っている Cookie は消しません）。

閉じたタブ

表示・操作

ウィンドウの見た目と、ワークスペースの切替方法の設定です。

言語の変更は開いている画面にも反映されます。名前や入力中の内容は変更しません。
管理パネルの検索ボックスの Enter・ワークスペース行のクリック・番号キー、クイックパレットの Enter で使う方法です。Ctrl+Enter（Mac は ⌘+Enter）は「休止して切替」との入れ替え（既定が休止なら「閉じる切替」）、Shift+Enter は「新しいウィンドウ」との入れ替えになります。行の ⏸ / ⧉ ボタンは設定に関係なくそれぞれ休止 / 新しいウィンドウです。休止については使い方ページを参照。
管理パネルの検索ボックスで、ワークスペース・ブックマークに加えて Chrome の閲覧履歴もタイトル・URL で検索します。任意の権限で、許可すると検索のときに履歴を読むだけで、保存や送信はしません。いつでも取り消せます。
タブ列の左端（固定タブの直後）に、今のワークスペースの名前と色のラベルを常に出します。ラベルをクリックすると開き、中のタブでワークスペースの切替・管理パネル・ブックマークを使えます。OFF にすると全ウィンドウのワークスペースタブを閉じます。

メモリ

タブのメモリ使用を抑える設定です。基本は Chrome 標準のメモリセーバーに任せ、ここは既定のままがおすすめです。

タブはタブバーに表示されたまま、クリックした時点で読み込まれます。推奨: ON
通常は Chrome 標準の「メモリセーバー」（chrome://settings/performance）に任せるのがおすすめです。 メモリセーバーはメモリ逼迫度やタブの状態（フォーム入力中・音声再生中など）を考慮して解放するため、こちらは「確実に N 分で解放したい」場合だけ使ってください。固定タブと音声再生中のタブは対象外です。 今すぐ解放したいときは、管理パネル左下の「💤 メモリ解放」。

タブの自動クローズ

長期間使っていないタブを、メモリ解放ではなく閉じる機能です。既定は OFF。閉じたタブは左の「閉じたタブ」から開き直せます。

15 分ごとに確認し、最後にアクティブにしてからこの期間が経ったタブを閉じます（最短 15 分）。閉じたタブは「閉じたタブ」（最大 500 件）や Chrome の履歴から開き直せます。 固定タブ・音声再生中のタブ・各ウィンドウのアクティブなタブ・seiton 自身のページは対象外で、ウィンドウの最後の 1 枚は閉じません。 閉じたタブはワークスペースの保存内容からも外れます。ワークスペースごとに、「ワークスペース」の節か管理パネルの ✎ で上書きできます。

除外する URL

ここに登録した URL のタブは、期間が過ぎても閉じません。1 行に 1 件。管理パネルの「開いているタブ」の 🛡 からも追加できます。書き方: github.com（サイト全体。サブドメインも含む）、mail.google.com/mail（ホスト + パスの先頭）、 https://example.com/docs（URL の先頭）。* は任意の文字列（例: *.example.com、example.com/*/edit）。

ブックマーク

ワークスペースに接続したブックマークフォルダの扱いです。

現在のウィンドウのアクティブなタブと同じ URL のブックマークだけが対象です（同期やインポートで作られたものは移動しません）。

ショートカット

現在この Chrome に割り当てられているキーです。

    同期

    Chrome / Edge のアカウントに紐づく拡張用の同期ストレージ（chrome.storage.sync）で、ワークスペース・セッション・設定を他のブラウザと同期します。seiton 独自のアカウントやサーバーはありません。ブラウザにログインして「拡張機能」の同期が ON のときに他の端末へ届きます（ログインしていない間はこの端末だけに保存され、ログインすると同期されます）。

    ON にすると、この端末の内容と同期ストレージの内容を合わせます（どちらも消えません。同じ ID のワークスペースは新しい方）。以後、変更は数秒後にまとめて書き込まれ、他の端末の変更は届き次第取り込まれます。OFF にしても同期ストレージの内容は残り、他の端末は同期を続けます。
    「同期データを削除」は同期ストレージを空にして、この端末の同期を OFF にします（各端末のローカルの内容は消えません）。

    同期される内容と制限

    • 同期するもの: ワークスペース（名前・色・アイコン・使うセッション・自動クローズの上書き・保存タブの URL とタイトル・固定・タブグループ・並び順）、セッション（名前）、設定（この「同期する」自体を除く）。接続したブックマークフォルダは「フォルダのパス」で同期し、他の端末では同じパスのフォルダを探して接続します（Chrome のブックマーク同期でフォルダが届けば自動で接続されます。無ければ未接続のまま）
    • 同期しないもの: 退避した Cookie（ログイン状態）、閉じたタブの履歴、タブの favicon と最終アクセス時刻、最後に使っていたワークスペース
    • 容量: 同期ストレージは全体で 100 KB（1 項目 8 KB、512 項目）です。タブは URL とタイトル（100 文字まで）だけに縮め、圧縮して保存します。それでも収まらないときは、最後に開いた日時が古いワークスペースから順にタブだけを同期から省きます（名前・色・セッションなどは必ず同期されます。省いたワークスペースは上に表示します）
    • 衝突: 同じワークスペースを 2 台で同時に変えたときは、更新時刻の新しい方が残ります。同じワークスペースを 2 台で同時に開いて使うと、最後にタブを操作した側の構成が保存されます（開いているウィンドウのタブは閉じたり増えたりしません）。片方で削除し、もう片方で変更した場合は、変更した方が残ります
    • 書き込み回数: Chrome の上限（120 回 / 分・1,800 回 / 時）に収めるため、変更から約 10 秒待ってまとめて書きます

    バックアップ

    ワークスペース・セッション・設定を JSON で保存 / 復元します。

    インポートすると現在のワークスペース・セッション設定はすべて置き換わります（ブックマークそのものは含まれません）。自動クローズで閉じたタブの履歴と退避した Cookie はエクスポート / インポートの対象外です。
