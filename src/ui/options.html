表示

ウィンドウの見た目に関する設定です。

タブ列の左端（固定タブの直後）に、今のワークスペースの名前と色のラベルを常に出します。ラベルをクリックすると開き、中のタブでワークスペースの切替・管理パネル・ブックマークを使えます。OFF にすると全ウィンドウのワークスペースタブを閉じます。

メモリ

タブのメモリ使用を抑える設定です。基本は Chrome 標準のメモリセーバーに任せ、ここは既定のままがおすすめです。

タブはタブバーに表示されたまま、クリックした時点で読み込まれます。推奨: ON
通常は Chrome 標準の「メモリセーバー」（chrome://settings/performance）に任せるのがおすすめです。 メモリセーバーはメモリ逼迫度やタブの状態（フォーム入力中・音声再生中など）を考慮して休止するため、こちらは「確実に N 分で休止させたい」場合だけ使ってください。固定タブと音声再生中のタブは対象外です。 今すぐ休止したいときは、管理パネルの ☰ 管理 → 「非アクティブなタブを休止」。

タブの自動クローズ

長期間使っていないタブを、休止ではなく閉じる機能です。既定は OFF。

15 分ごとに確認し、最後にアクティブにしてからこの期間が経ったタブを閉じます（最短 15 分）。閉じたタブは管理パネルの ☰ 管理 → 「閉じたタブ」（最大 500 件）や Chrome の履歴から開き直せます。 固定タブ・音声再生中のタブ・各ウィンドウのアクティブなタブ・seiton 自身のページは対象外で、ウィンドウの最後の 1 枚は閉じません。 閉じたタブはワークスペースの保存内容からも外れます。ワークスペースごとに、管理パネルの ✎ や「ワークスペースの管理」で上書きできます。

除外する URL

ここに登録した URL のタブは、期間が過ぎても閉じません。1 行に 1 件。管理パネルの「開いているタブ」の 🛡 からも追加できます。書き方: github.com（サイト全体。サブドメインも含む）、mail.google.com/mail（ホスト + パスの先頭）、 https://example.com/docs（URL の先頭）。* は任意の文字列（例: *.example.com、example.com/*/edit）。

閉じたタブの履歴

自動クローズで閉じたタブの履歴（最大 500 件）です。開き直すには管理パネルの ☰ 管理 → 「閉じたタブ」。エクスポート / インポートの対象外です。

セッション（Cookie / ログイン状態の分離）

セッションの追加・名前変更・削除は管理パネルの ☰ 管理 → 「セッションの管理」で行います。ここでは Cookie（ログイン状態）の状態を確認します。

セッションごとに Cookie（ログイン状態）が分かれます。別のセッションを使うワークスペースに切り替えるとき、今の Cookie をそのセッション用に退避してすべて消し、切替先のセッションの Cookie を復元します （Chrome のプロファイルを切り替えるのに近い動き）。同じサイトに別のアカウントでログインしたままセッションごとに使い分けられます。 Chrome 全体で同時に使えるセッションは 1 つで、切替は他のウィンドウにも及びます（別のセッションのワークスペースを開いているウィンドウは、次の読み込みから切替先のログイン状態になります）。 Cookie を読み書きする権限（すべてのサイト）が必要で、管理パネルでセッションを追加するときに Chrome が確認を出します。localStorage などサイト側の他の保存領域は分けません。 退避した Cookie はこの拡張の保存領域（chrome.storage.local）に平文で保存され、エクスポートには含まれません。
「退避した Cookie を削除」は退避した分だけを消します（今 Chrome に入っている Cookie は消しません）。

ブックマーク

ワークスペースに接続したブックマークフォルダの扱いです。

現在のウィンドウのアクティブなタブと同じ URL のブックマークだけが対象です（同期やインポートで作られたものは移動しません）。

ショートカット

現在この Chrome に割り当てられているキーです。

    バックアップ

    ワークスペース・セッション・設定を JSON で保存 / 復元します。

    インポートすると現在のワークスペース・セッション設定はすべて置き換わります（ブックマークそのものは含まれません）。自動クローズで閉じたタブの履歴と退避した Cookie はエクスポート / インポートの対象外です。
